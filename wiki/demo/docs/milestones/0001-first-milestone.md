# The first milestone: a notes home that reads

## Outcomes and acceptance
- A person keeps Markdown notes in a repository and opens them in the
  local wiki, pages following the files as saved.
- An old note reads in place, per FR-001, demonstrated on the fixture
  chain of this repository.
- A dead link is shown and named, per FR-002, covered by a test.

## Exclusions
Writing and editing from the wiki; several products in one place;
publishing anywhere.

## Scope decisions
The finding budget stays at the setup value; no carryover is agreed.

## Next horizon
The model side of the product: a notes home that knows its own structure.
