# FR-002 — A link that leads nowhere is shown, never followed

Serves: UC-001
Verified by: test

## Requirement
A link in a note that names no page of the notes home is shown as its
text, and the note says, beside the link, that it leads nowhere in this
home.

## Rationale
A reader who follows a dead link loses the note they came back to; the
words stay, so the sentence still reads.
