# FR-001 — An old note reads in place

Serves: UC-001, US-001
Verified by: demonstration

## Requirement
A note written at least two weeks ago opens in the reading view with its
text on the shared reading tokens, its column at the accepted measure, and
no change in its layout for as long as the reader reads it.

## Rationale
The return is where a note is lost: a reader who fixes a page before
reading it is editing, not reading (H-001, S-001).

## Sources
- S-001 00:01:12-00:02:05 "When I open an old one I fix it first — size, links, the works — before I can actually read it."
