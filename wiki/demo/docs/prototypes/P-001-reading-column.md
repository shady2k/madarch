# P-001 — The reading column on the shared tokens

Tests: H-001
Code: prototypes/leftover-notes

## What it tries
Whether a note page on the shared reading tokens — the accepted type
scale, the 60 to 75 character column, no layout shift — reads without a
fixing edit first, for one reader across two weeks.

## How to run
Open `prototypes/leftover-notes/index.html` in a browser; it holds the
static note page the two weeks of reading run against.
