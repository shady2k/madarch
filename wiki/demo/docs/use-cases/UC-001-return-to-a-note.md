# UC-001 — Return to a note written days ago

Serves: US-001
Level: user goal
Primary actor: a person who keeps notes
Scope: the Fieldnote notes home
Scenario: return-to-note
Trigger: the reader opens a note they wrote at least two weeks ago

## Preconditions
The note exists in the notes home; the reader opens the wiki.

## Success end condition
The note reads in place: the text sits on the shared tokens, every link
resolves, and nothing moves while the page settles.

## Failed end condition
The note shows broken or half-formatted, and the reader is told which
link does not resolve.

## Main success scenario
1. The reader opens a note from the notes home.
2. The note shows with its text on the shared tokens, at the column the
   reading tokens set.
3. The reader follows a link inside the note, and the linked page opens.
4. The reader goes back to the note, and it stands where it stood.

## Extensions
- 2a the note holds a link to a page the home does not hold: the link is
  shown as its text, and the reader is told it leads nowhere.
- 3a the linked page has changed since the last visit: the new text is
  shown, and nothing else on the page moves.
