# Q-002 — Does the reading view remember the last position?

Concerns: VISION
Who can answer: whoever runs the reading study

## Question
When a reader returns to a long note, should the view open at the place
they left, or always at the top?

## What settles it
The reading study's notes on how people come back to a note.

## Answer
A first pass with five readers showed a quiet top-of-page return was
never missed; the position memory is dropped from the scope.
